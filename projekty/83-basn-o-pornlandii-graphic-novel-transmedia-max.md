# Project 83 — Baśń o Pornlandii Graphic-Novel & Transmedia World MAX

## Status
PROPOSED → ARCHITECTURE BASELINE → PROJECT GENESIS 2026-09-10

## Mission
Create a high-end graphic-novel adaptation of *Baśń o Pornlandii* as a visually coherent dystopian world in which architecture, gesture, silence, materiality and controlled intimacy communicate the story as strongly as dialogue.

## Why this is new
The supplied project is a dedicated graphic-novel adaptation with its own world-building, character system, layout grammar, production requirements and transmedia plan. It is not owned by Project 73, which is specifically a Człowiek Roku evidence-driven game, nor by Project 82, which owns the CCR universe.

## World as antagonist
The source describes the city as an active system of suppression rather than neutral scenery. The visual language therefore treats architecture as an agent of control:

```text
ARCHITECTURE
 ↓
MOVEMENT CONSTRAINT
 ↓
GESTURE / PRIVACY
 ↓
CHARACTER RESPONSE
 ↓
NARRATIVE CONSEQUENCE
```

## Visual pillars
- biomorphic sterile architecture / curved spaces;
- mercury-like material metaphors;
- cold neon versus warm historical memory;
- Future Noir and documentary-photography influence;
- controlled geometry contrasted with expressive human marks;
- visualized silence and missing sensory channels.

## Character system
The supplied adaptation centers Rocco, Mira and Andrzej, plus faceless system enforcers. Each receives a stable visual grammar covering silhouette, gesture, lighting, environment interaction and emotional state.

## Layout semantics
The gutter is treated as narrative space. Missing information, silence and sensory deprivation can be represented through deliberate negative space, interrupted sequences and controlled panel rhythm. The page must remain readable; formal experimentation cannot obscure essential narrative information.

## OSINT boundary
The supplied report contains OSINT-derived statements about the author. Those statements remain source claims with provenance labels. They must not be silently converted into biographical facts in marketing or the story.

## Transmedia
The project may use optional digital supplements, archival documents or AR elements. These must be explicitly identified as extensions of the work, versioned, and unable to alter the meaning of the physical book without user action.

## Safety / content boundary
The work can address sexuality, control, coercion and dystopian intimacy as literary themes. The production system does not use covert psychological manipulation of readers, subliminal commands or exploitative behavioral optimization as engagement requirements.

## Quality gates
1. Fidelity to the approved source/canon.
2. Visual consistency.
3. Chronology and continuity.
4. Character-state consistency.
5. Typography/readability.
6. Print proof and color management.
7. Provenance review for external claims.
8. Accessibility review.
9. Independent editorial review.

## Definition of done
A volume is validated when its narrative, art, lettering, continuity, provenance and physical proof pass all declared gates and its optional digital layer remains consistent with the print edition.
