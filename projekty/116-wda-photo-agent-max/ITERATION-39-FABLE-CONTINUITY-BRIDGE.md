# P116 — Iteration 39: Fable Character-Continuity Bridge

## Trigger

The Fable corpus provides an external reference for persistent character identity across story chapters and multimodal outputs.

## Upgrade

P116's existing identity/structure lock is promoted from a photographic quality mechanism to a reusable **Character Reference Contract** for P118.

```text
PHOTO REFERENCE
      ↓
IDENTITY / STRUCTURE LOCK
      ↓
CHARACTER REFERENCE PACK
      ↓
SCENE GENERATION
      ↓
P116 VISUAL QUALITY GATE
      ↓
P118 STORYWORLD CONTINUITY
```

## Reusable contract

The character reference pack should be capable of carrying:

- canonical reference images;
- facial/structural invariants;
- wardrobe/style constraints;
- pose/proportion constraints where relevant;
- allowed transformations;
- scene-specific overrides;
- provenance and revision history;
- consent state for real-person references.

P116 remains responsible for visual diagnosis, identity preservation, controlled image editing and photographic quality. P118 owns narrative continuity and chapter state.
