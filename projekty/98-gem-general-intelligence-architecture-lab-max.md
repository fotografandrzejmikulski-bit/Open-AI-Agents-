# Project 98 — GEM General Intelligence Architecture & Verification Lab MAX

## Status
PROPOSED → ARCHITECTURE BASELINE → PROJECT GENESIS 2026-09-10

## Mission
Develop a research and verification architecture for a general-purpose cognitive AI ecosystem by decomposing the GEM concept into independently testable capabilities: general reasoning, specialist routing, persistent memory, tool use, strategic planning, probabilistic forecasting and continuous adversarial assurance.

## Distinct boundary
The portfolio already contains agent runtimes, model routing, compound reasoning, research orchestration, OmniCore substrate and assurance projects. P98 does not replace them. It is the integration-and-evaluation program whose unit of progress is demonstrated cross-domain capability rather than infrastructure ownership.

## Conceptual architecture

`foundation models / MoE → capability router → specialist experts → shared memory/knowledge graph → planner → authorized tools → observation → verifier/red team → evidence store → learning/evaluation loop`

### Capability tracks

1. **General Reasoning Core** — benchmarked reasoning across heterogeneous tasks.
2. **Specialist Expert Mesh** — law, finance, OSINT, technology/cybersecurity and strategy as separately evaluated capabilities.
3. **The Vault** — provenance-aware vector retrieval + knowledge graph memory.
4. **The Oracle** — probabilistic/causal forecasting with calibrated uncertainty rather than deterministic future claims.
5. **Agentic Planner** — goal decomposition, resource allocation and iterative execution.
6. **Nemesis Red Team** — continuous adversarial evaluation for prompt injection, data poisoning, goal drift and unsafe plans.
7. **Constitution / Policy Layer** — authorization and safety policy outside the model's claimed authority.
8. **Human Critical-Decision Gate** — mandatory approval where consequence, law, finance or safety warrants it.

## Core invariants

- intelligence is not authorization;
- memory is not authorization;
- tool access is not permission to use a tool;
- model proposals require independent policy evaluation;
- probabilistic forecasts must report calibration and uncertainty;
- simulations are not evidence of real-world performance;
- AGI, consciousness and human-level generality are hypotheses until demonstrated by reproducible evaluations.

## Verification program

- cross-domain benchmark suite;
- specialist-vs-generalist routing evaluation;
- long-horizon task completion with independent postcondition checks;
- memory retrieval precision/recall and provenance audits;
- forecast calibration/Brier-style evaluation where applicable;
- red-team attack suites for prompt injection and data poisoning;
- goal-drift and authority-escalation tests;
- ablation studies to identify which capabilities actually cause improvements;
- reproducible experiment ledger with model/version/data/config hashes.

## Safety boundary
The source material mentions hacking, dark-web OSINT and offensive scenarios. P98 retains these only as bounded defensive evaluation domains, authorized test environments and threat-model inputs. It does not create credential theft, covert intrusion, destructive automation or unrestricted offensive capability.

## Maturity
Research architecture baseline. No claim of AGI, consciousness, superintelligence or reliable future prediction is established by the source material.

The God-Level/OCAA and OMEGA-X sources add explicit research tracks for Code World Models, object/meta-level reasoning (MARS), hierarchical memory concepts (R3Mem/Titans), neuro-symbolic verification and AlphaEvolve-style population search.
