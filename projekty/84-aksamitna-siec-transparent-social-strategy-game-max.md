# Project 84 — Aksamitna Sieć: Transparent Social Strategy Game MAX

## Status
PROPOSED → ARCHITECTURE BASELINE → PROJECT GENESIS 2026-09-10

## Mission
Develop the *Aksamitna Sieć / The Velvet Lattice* concept into a premium physical social-strategy game built around influence, negotiation, uncertainty and tactile components, while explicitly excluding covert psychological manipulation, compulsive-use optimization and deceptive marketing.

## Source-derived core
The supplied design defines a 3–6 player, 60–90 minute noir strategy game with asymmetric roles, influence tokens and a physical Whispering Tower. The tower is a smoked translucent structure with internal pins/traps inspired by Plinko/Pachinko-like physical uncertainty.

## Safe design transformation
The source frames variable-ratio reinforcement, hidden persuasion and compulsion as objectives. This project retains the **dramatic game mechanics** but converts them into transparent, player-readable rules.

```text
SOCIAL STRATEGY
 + NEGOTIATION
 + PHYSICAL UNCERTAINTY
 + ASYMMETRIC POWERS
 + OPTIONAL COLLECTION
 → FAIR, DISCLOSED GAMEPLAY
```

## Core components
- Whispering Tower physical resolution device.
- Influence tokens.
- Player masks/roles.
- Pisma / action cards.
- Ledger / scoring system.
- Premium board and packaging.

## Rules architecture
Every consequential effect has an explicit rules definition. Physical uncertainty may be randomized, but probabilities and resolution rules are documented for testing. No hidden rule changes based on player vulnerability, spending behavior or inferred psychology.

## Social interaction
Roles can reward observable table behavior such as negotiation, alliances, bluffing and declared rhetorical challenges. A player must always be free to refuse a social prompt without punishment outside the ordinary rules of the game.

## Physical resolution engine
```text
ACTION
 ↓
TOKEN / COMPONENT
 ↓
TOWER RESOLUTION
 ↓
OBSERVABLE OUTCOME
 ↓
RULE LOOKUP
 ↓
STATE UPDATE
```

The tower is a game-state mechanism, not a behavioral-control device.

## Digital companion
An optional companion can provide rules lookup, setup assistance, accessibility support, statistics and replay logs. It must not secretly alter odds or target vulnerable players.

## Marketing boundary
The source proposes ARG/secret-club framing, hypnotic copywriting and recruitment language. Project 84 replaces this with transparent positioning: mystery and noir atmosphere may be part of the fiction, but advertising must clearly identify the product and commercial terms.

## Evaluation
- strategic depth;
- interaction quality;
- rules comprehension;
- physical reliability;
- fairness of tower outcomes;
- replayability;
- accessibility;
- player-reported enjoyment;
- absence of coercive/deceptive mechanics.

## Prototype gates
1. 3D-print tower prototype.
2. Mechanical reliability tests.
3. Distribution/repeatability measurements.
4. Rules simulation.
5. Blind playtest.
6. Accessibility review.
7. Independent rules audit.
8. Manufacturing proof.

## Definition of done
The game is production-ready when the physical resolution system is repeatable within declared tolerances, rules are understandable without hidden psychological instructions, strategic interaction is fun without coercion, and the complete component set passes manufacturing and playtest QA.
