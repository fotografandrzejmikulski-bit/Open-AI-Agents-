## Project 77 rationale
The Principia corpus is not merely a literature survey: it proposes a coherent new mathematical ontology, explicit axioms and claimed consequences. The correct engineering response is neither blind acceptance nor simple archival storage. Project 77 makes the claims falsifiable through formal definitions, counterexample search, independent derivation and machine-checked proof.

## Project 78 rationale
The Lotto artifact contains a concrete HTML prototype and a domain-specific protocol with statistical, physical and multi-agent components. The existing stochastic projects provide generic machinery, but not a dedicated lottery-randomness audit product. Project 78 therefore owns the bounded domain implementation while explicitly rejecting guaranteed-win or false-certainty claims.
