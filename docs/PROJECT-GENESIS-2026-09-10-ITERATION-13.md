## Existing-project evolution

### Project 53
- Tarot becomes an explicit lineage-aware `DeckSchema` family.
- 62/78/79/97-card variants and different court structures are represented as configuration.
- Apeiron HEX/checksum and Stack Trace mechanics are formalized as deterministic symbolic/game rules.

### Project 54
- The five dossier/profiling prompts become a defensive test corpus.
- Identity, ideology, motive, family/business relation and behavioral prediction are explicitly typed as evidence/inference/hypothesis.
- Consent, disclosure and vulnerability-targeting checks are added to influence analysis.

### Project 57
- PUI Android sensor fusion, public-profile evidence and consent metadata become typed multimodal evidence classes.
- PUI launcher evaluation includes privacy, disclosure, reversibility and agency gates.

### Project 61
- Godot 4.x + Android launcher + 3DGS becomes a concrete implementation branch.
- Lifecycle/render freezing, SOGS/quantization and Kotlin/GDScript/Compute Shader boundaries become testable gates.
- Affective signals remain UX/accessibility evidence and never become capability authority.

### Project 71
- Tarot taxonomy and Apeiron 78-card structure feed the manufacturing-aware deck compiler.
- HEX overlays, optical layers, stack geometry and protocol state become ArtifactSpec fields.

### Project 78
- Lottery `GameMatrix(m,n,p,q)`, multi-pool probabilities, wheeling designs, Keno parameterization and paytable/EV analysis are added to the audit model.
- Prediction claims remain outside the project mission.

## First validation milestones

1. Build a versioned Tarot `DeckSchema` test corpus covering 62/78/79/97-card structures.
2. Implement a deterministic Apeiron HEX/checksum overlay simulator and verify overflow/remainder semantics.
3. Create a PUI Android prototype benchmark matrix for raw 3DGS vs compressed representations and launcher-visible/obscured lifecycle states.
4. Create an OSINT dossier evaluation corpus with source conflicts, identity ambiguity and unsupported motive/prediction claims.
5. Add a consent metadata schema and test disclosure/retention/withdrawal completeness.
6. Extend Project 78 with exact probability and wheeling calculators whose outputs are independently reproducible.

## Safety / epistemic gates

- No covert personal profiling or psychological diagnosis.
- No personalized behavioral targeting.
- No guaranteed lottery predictions.
- No symbolic interpretation presented as factual prediction.
- No affective signal may grant permission or capability.
- No personal-data workflow promoted to legal compliance without current legal review.
