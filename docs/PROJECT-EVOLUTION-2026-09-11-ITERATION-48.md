## Architectural delta

Previous doctrine:
OBSERVE → PLAN → AUTHORIZE → ACT → READBACK → VERIFY

Expanded engineering chain:
DISCOVER CAPABILITY
→ SELECT ADAPTER
→ AUTHENTICATE
→ AUTHORIZE
→ READ REPOSITORY/ENVIRONMENT STATE
→ PLAN
→ EXECUTE IN CONTROLLED RUNTIME
→ TEST
→ BUILD
→ PROVENANCE
→ DEPLOY
→ OBSERVE
→ VERIFY
→ PROMOTE / ROLLBACK

## New invariants reinforced

- authenticated ≠ authorized;
- token-valid ≠ action-allowed;
- valid JSON ≠ trusted instruction;
- recon finding ≠ identity proof;
- tool availability ≠ authorization;
- working-tree view ≠ canonical repository history;
- SQL success ≠ query optimality;
- VPN/TLS ≠ complete Zero Trust;
- generated artifact ≠ verified runtime state.
