## Creation rationale
### Project 90
The SOP corpus supplies a reusable transformation from observed work to process graphs, evidence-linked procedures, naive-user validation and controlled change management. This is broader than one application and is not owned by an existing project.

### Project 91
The persona corpus defines a repeatable model-training/evaluation problem involving behavioral specifications, datasets, post-training, activation analysis and safety regressions. Existing PUI/persona work treats persona primarily as an interface layer; Project 91 owns the experimental model-engineering layer.

## Rejection rules
No project is created merely because a source has a different title, implementation language or deployment target. New genesis requires a distinct reusable mission, architecture and verification boundary.

## Security / epistemic handling
- The mobile spyware report is retained only as defensive security/threat-model input. No offensive stealth, exploit-chain or credential-acquisition capability is promoted.
- VANTAGE POINT's scanner is explicitly treated as simulated prototype behavior, not live reconnaissance.
- Mathematical claims remain claim/proof-status data; experiments do not become proofs automatically.
- CCR's light/time mechanics remain fictional game-world abstractions.
- Personality engineering does not imply consciousness and cannot grant authority.
