## Cross-project evolution

The iteration strengthens a common control loop:

OBSERVE → CLASSIFY/ESTIMATE → UNKNOWN/AMBIGUITY → POLICY → CAPABILITY GATE → EXECUTE/SIMULATE → VERIFY → EVIDENCE → RECOVER/EVOLVE

This explicitly separates model inference from authority and separates network resilience from hardware attestation.
