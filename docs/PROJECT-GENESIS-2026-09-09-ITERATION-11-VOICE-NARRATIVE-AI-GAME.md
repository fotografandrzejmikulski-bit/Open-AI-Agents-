# Project Genesis — Iteration 11 — Voice-Narrative AI Game Engine MAX

## Decision

Create **Project 81 — Voice-Narrative AI Game Engine MAX**.

## Trigger

The newly supplied corpus contains three overlapping specifications for `Szept Wyroczni / Whisper of Fate / Project Midas`: a mobile game whose primary interaction is voice, whose central fictional character is an AI Oracle, and whose gameplay can be driven by natural-language intent. The expanded version includes Unity implementation, local/edge voice-processing concepts, notifications, audio mechanisms and an in-game economy.

## New capability boundary

The source corpus exposes one material portfolio gap:

> **A digital, voice-native AI-character game runtime that converts natural-language/voice interaction into typed game commands while keeping game state, RNG, economy and progression authoritative and independently verifiable.**

This is distinct from:

- physical card interfaces;
- general multimodal interfaces;
- compound reasoning engines;
- generic adaptive game design;
- narrative game content.

Therefore Project 81 is justified.

## Architectural breakthrough

The core design principle is:

```text
PROBABILISTIC AI / VOICE / NARRATIVE
                 ≠
AUTHORITATIVE GAME RULES / STATE / ECONOMY
```

The AI may propose. The authoritative runtime decides whether a typed command is legal and executes the resulting state transition.

## Safety transformation

The source includes proposals for covert commands, emotional monetization and compulsive reinforcement. Those are not adopted as project requirements.

Project 81 instead uses:

- explicit consent and microphone status;
- minimized/local voice processing where feasible;
- fair, replayable RNG;
- no model-controlled odds;
- no emotional punishment for non-payment;
- transparent purchases;
- non-voice accessibility;
- adversarial testing of AI/game-state confusion.

## First credible demonstration

A validated MVP should demonstrate:

```text
spoken request
   ↓
intent extraction
   ↓
typed command
   ↓
authoritative validation
   ↓
state transition
   ↓
postcondition
   ↓
voice/narrative response
```

with deterministic replay and an auditable event trail.

## Evidence boundary

Project 81 is an architecture candidate, not proof that the proposed commercial concept will become a global hit. The uploaded material does not establish the effectiveness of covert persuasion, emotional monetization or compulsive design, and those mechanisms are intentionally excluded from the validated architecture.

## Promotion gate

Project 81 remains **PROPOSED / ARCHITECTURE_BASELINE** until the MVP demonstrates the complete voice → intent → command → authoritative state → verification loop under adversarial tests.
