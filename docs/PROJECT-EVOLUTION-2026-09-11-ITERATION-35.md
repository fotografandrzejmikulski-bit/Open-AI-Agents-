## New boundary

The source integrates components that individually belong to existing projects, but it also defines a higher-level autonomous engineering control loop that coordinates them. This boundary becomes P115.

## Required invariants

- self-improvement never bypasses verification;
- memory mutation is provenance-aware and versioned;
- generated code/configuration is untrusted until tested;
- model capability and MCP capability do not grant authorization;
- simulation is not execution evidence;
- source-reported benchmarks are not reproduced benchmarks;
- every promoted mutation has rollback and regression evidence;
- security-control research is isolated from production authorization paths.
