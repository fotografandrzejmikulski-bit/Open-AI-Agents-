## New project threshold

A new numbered project requires all of the following to be substantially true:

1. It represents a distinct product/system capability rather than a document topic.
2. It has an independent deliverable and Definition of Done.
3. Existing projects cannot absorb the capability without destroying a useful boundary.
4. It has a clear verification path.
5. Its dependencies and safety boundary can be stated explicitly.
6. The project adds portfolio value rather than duplicating an existing title.

Projects 73 and 74 satisfy this threshold.
