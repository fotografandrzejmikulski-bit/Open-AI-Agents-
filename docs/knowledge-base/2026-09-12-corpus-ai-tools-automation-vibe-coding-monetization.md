## Security boundary

Secret handling, environment isolation, repository provenance, frequent commits and testing are treated as baseline controls. Agentic coding must remain under the P100 lifecycle:

`OBSERVE → PLAN → AUTHORIZE → ACT → READBACK → VERIFY`

No coding agent, prompt, template, deployment platform or automation recipe can self-authorize consequential actions.
