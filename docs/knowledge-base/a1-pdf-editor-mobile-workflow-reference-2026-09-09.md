# A1 PDF Editor — Mobile Workflow Reference

## Source boundary

Derived from `Introduction_A1_PDF.pdf`. This artifact records the application's navigation and workflow concepts shown in the supplied introductory guide.

## Primary navigation

The guide identifies three central areas: `Home`, `Create New` and `Tools`.

- **Home** contains recently opened files and favourites.
- **Create New** contains common creation workflows such as creating a blank PDF and camera scanning.
- **Tools** exposes conversion, creation and PDF editing functions.

## Creation workflows

The guide describes creating a blank PDF, using the device camera as a scanner, and importing a file from the device for editing.

## Document organization

The guide also describes a Pages navigation surface for changing PDF structure while a document is open.
