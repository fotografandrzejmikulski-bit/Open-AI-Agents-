# CogniSync Grant Source Corpus

This document records the source lineage used to shape the CogniSync grant artifact. It is a provenance index, not a claim that every source statement is technically validated.

## Supplied source materials

The project was developed from the supplied research corpus, including material covering:

- local Gemma 3 execution, GGUF quantization, CPU/GPU offloading, local search and verification loops;
- Rclone / Google Drive integration patterns;
- MCP and A2A architecture concepts;
- background professional-agent workflows and human-in-the-loop control;
- Engine-on-Engine creator architecture and visual authoring concepts;
- influence systems and defensive human-agency / media-literacy analysis;
- productized AI content workflows.

## Translation into the grant project

Only the material relevant to the grant was retained in the CogniSync submission repository. The broader research directions were moved into this repository's `projekty/` and `docs/knowledge-base/` layers.

The key design transformation was:

`source concept → engineering hypothesis → implemented control → executable verification → measured evaluation`

## Important provenance rule

Source material may motivate a design direction, but it does not by itself establish that an implementation works, that a third-party service is currently available, or that a performance target has been achieved. Such claims require separate evidence.

The grant repository therefore maintains a claim ledger and avoids presenting future cloud deployment as completed work.
