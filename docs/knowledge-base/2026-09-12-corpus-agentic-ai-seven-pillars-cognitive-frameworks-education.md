## Seven pillars

1. Autonomy — independent operation and action initiation.
2. Goal-Directed Planning — goal decomposition, adaptive planning and execution.
3. Communication & Collaboration — agent/agent and agent/human interaction.
4. Reasoning & Decision Making — contextual reasoning and decisions.
5. Tool Use & Environment Interaction — APIs, browsers, code and external tools.
6. Memory & Learning — persistent/retrievable context and knowledge.
7. Safety, Alignment & Evaluation — bounded, reliable behavior and evaluation.

The named frameworks/tools in the source are retained as source-derived examples, not as verified current capability claims.

## Architectural interpretation for P100

The seven pillars map cleanly to the existing NeXus AI Code OMEGA-X control plane:

`GOAL → PLAN → CAPABILITY SELECTION → AUTHORIZATION → TOOL/ENVIRONMENT ACTION → MEMORY/STATE → READBACK → EVALUATION`

Autonomy is therefore constrained by policy, capability leases, sandboxing and postcondition verification. Safety/evaluation is a cross-cutting control plane, not merely pillar seven.
