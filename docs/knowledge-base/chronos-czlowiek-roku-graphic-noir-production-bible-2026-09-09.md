# Chronos: Człowiek Roku — Graphic Noir Production Bible

## Source boundary

Derived from `Komiksowa Adaptacja _Człowieka Roku_.pdf`. The document presents a production bible for a graphic adaptation using documentary-noir aesthetics, OSINT/topographic context and a fact/fiction separation model.

## Methodology

The source proposes triangulation of:

1. source-text analysis;
2. OSINT and topographic verification of locations;
3. systemic/legal/social context.

The intended visual language is not a simple illustration of prose: the document frames the graphic novel as a visual reconstruction supported by evidence.

## Visual grammar

The source uses high-contrast noir, documentary realism, recurring symbolic objects, environmental details and location-specific composition. Character dossiers define visual attributes, props and recurring motifs to maintain continuity across scenes.

## Narrative structure

The supplied sequence plan is organized into multi-part arcs covering the protagonist's personal collapse, institutional conflict, public struggle and an unresolved later period. Locations and scene mechanics are specified at sequence level, enabling storyboard, asset and panel planning.

## Production data model

```text
SOURCE EVENT
 → EVIDENCE / PROVENANCE
 → SCENE
 → LOCATION
 → CHARACTER STATE

```

## Safety / epistemic boundary

The production bible contains allegations and characterizations concerning real people and institutions. Those claims must remain attributed and evidence-bounded. OSINT material is not automatically fact. Public-source references should be independently checked before publication.
