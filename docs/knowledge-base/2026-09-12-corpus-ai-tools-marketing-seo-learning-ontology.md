## 2. Paid/free substitution model

The corpus repeatedly pairs paid and free products for approximately similar tasks. This is useful as a discovery mechanism but does not prove functional equivalence.

A substitution candidate must be evaluated against:

```text
CAPABILITY
+ INPUT / OUTPUT MODALITY
+ QUALITY THRESHOLD
+ CONTEXT / FILE LIMITS
+ INTEGRATIONS
+ PRIVACY / DATA RESIDENCY
+ LATENCY
+ COST
+ LICENSE / TERMS
+ PROVENANCE
```

Therefore:

`FREE ≠ UNRESTRICTED`
`CHEAPER ≠ EQUIVALENT`
`LISTED ALTERNATIVE ≠ VERIFIED SUBSTITUTE`

Silent substitution is prohibited when quality, privacy, authorization or output requirements materially change.

## 4. SEO subsystem

The SEO images identify recurring tool families:

### Keyword research
Google Keyword Planner, AnswerThePublic, Keyword Explorer, Google Trends, Keyworddit and comparable keyword tools.

### Link building
Link Explorer, Link Miner, disavow tooling, backlink checking and detailed backlink analysis.

### On-page / structured data
Yoast SEO, Rich Results Test, Schema Markup Generator, SERP simulation and structured-data testing.

### Crawling / indexing
Beam Us Up, Redirect Path, Link Redirect Trace, Screaming Frog and SEOlyzer.

### Analytics / measurement
Google Analytics, Google Data Studio/Looker Studio, Search Console and SEO analytics products.

### Other SEO support
PageSpeed Insights, Google Business Profile, HARO-style outreach, Similarweb and broader SEO suites.

The architecture implication is that SEO should be modeled as an evidence-producing pipeline rather than a single "SEO tool" capability.
