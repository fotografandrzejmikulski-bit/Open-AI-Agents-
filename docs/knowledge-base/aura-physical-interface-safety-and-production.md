# AURA — Physical Interface, Production and Cognitive-Safety Extraction

## Source basis

Derived from the supplied *AURA: The Collective — Specyfikacja Techniczna i Projektowa (Wersja Produkcyjna)*. Two supplied AURA PDFs contain materially duplicated content; they are treated as one source lineage rather than duplicated knowledge.

The source specifies a 60-card physical puzzle deck with Black Core stock, hidden Waterless UV printing, reversible thermochromic masking and tactile finishes. fileciteturn326file0L13-L25

## Physical technology

The source defines a layered manufacturing concept:

1. Black Core card substrate;
2. hidden UV print;
3. reversible thermochromic masking activated by heat;
4. Soft Touch and selective 3D tactile finish.

This is retained as a physical-interface pattern for the existing Project 50/53 work.

## Special effects

The supplied design includes mirror/metallic foil, scented varnish and UV-visible markings as anomaly-card effects. fileciteturn326file0L124-L142

The engineering extraction separates **sensory mechanics** from **behavioral objectives**. Materials such as thermochromic ink, tactile varnish, NFC and UV printing may be used to create discovery and interaction, but they do not become hidden behavioral-control channels.

## Packaging and phygital bridge

The source specifies a book-style magnetic box, Soft Touch finish, thermochromic seal, flocked insert and NFC-triggered web experience. fileciteturn326file0L144-L159

OmniCore interpretation:

`physical artifact -> explicit digital handoff -> authenticated state -> reversible interaction`

NFC is an entry mechanism, not an implicit permission grant.

## Onboarding

The source uses staged onboarding around touch, bluffing and set collection. fileciteturn326file0L160-L174

The existing game-safety architecture converts the engagement-oriented portions into transparent game mechanics. Rules must be explicit, outcomes auditable and player exit straightforward.

## Cognitive-safety transformation

The source explicitly describes embedded NLP commands, risk-taking encouragement, variable reward and an "Addiction Loop". fileciteturn326file0L26-L29 fileciteturn326file0L613-L621

These elements are **not adopted as product optimization targets**. They become defensive design requirements:

- no covert commands intended to bypass critical thinking;
- no optimization for compulsive repetition;
- no vulnerability-targeted personalization;
- no hidden behavioral state changes;
- transparent probability/rules;
- visible opt-out and break mechanisms;
- sensory effects separated from coercive objectives.

## Production/QC knowledge

The source proposes Polish suppliers and emphasizes batch-level QC because of the multi-layer physical process. fileciteturn326file0L223-L236

For Project 50/53, the production contract should test:

- thermochromic activation threshold and hysteresis;
- print registration;
- opacity and hidden-layer legibility;
- tactile finish durability;
- NFC read reliability;
- card-to-card consistency;
- environmental stability;
- packaging tolerance;
- accessibility of the interaction.

Supplier specifications are treated as claims until independently measured.

## Marketing transformation

The supplied campaign uses mystery, exclusivity, sensory stimulation and social/behavioral triggers. fileciteturn326file0L175-L220

OmniCore preserves the **aesthetic and experiential** layer while removing coercive or deceptive influence. Marketing may create curiosity; it must not manufacture dependency or conceal material decision-relevant information.

## Core invariants

1. Physical effects are interfaces, not hidden authority channels.
2. Sensory feedback cannot authorize actions.
3. Symbolic/card content is interpretive, not empirical truth.
4. Engagement metrics cannot be optimized through covert psychological control.
5. Probability and rules are disclosed where decision-relevant.
6. NFC does not bypass digital authorization.
7. Production claims require physical QC measurement.
8. Player agency, reversibility and opt-out remain first-class product properties.
