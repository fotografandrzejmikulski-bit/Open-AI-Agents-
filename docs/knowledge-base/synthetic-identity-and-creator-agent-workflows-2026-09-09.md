# Synthetic Identity & Creator Agent Workflows

## Source boundary

Derived primarily from `Instrukcja Krok po Kroku i AI.pdf`. The source covers virtual-influencer production, character consistency, LoRA, ControlNet, content workflows, platform monetization and agentic automation. This artifact retains production and workflow engineering while excluding covert impersonation, deceptive relationship manipulation and exploitative targeting.

## Character Consistency Engineering

The source defines a workflow based on a stable archetype, fixed visual attributes, a reusable base prompt, a reference dataset, LoRA training and post-training validation. It recommends varied lighting, angles and expressions while preserving invariant character features.

ControlNet is described as a composition/pose/depth control layer. The source identifies OpenPose for skeletal pose, Canny/Depth for contours/depth and inpainting for selective edits while preserving other scene elements.

## Agentic production loop

Reusable architecture:

```text
CHARACTER SPEC
 → DATASET / CAPTIONS
 → GENERATION
 → CONSISTENCY CHECK
 → POSE / COMPOSITION CONTROL
 → EDIT / QA
 → PUBLISH
 → METRICS
 → ITERATE
```

The important engineering principle is separation of invariant identity state from mutable scene, wardrobe, pose and context state.

## Monetization model

The source describes subscriptions, PPV and custom digital orders as major monetization mechanisms and compares creator platforms. These market figures are retained as historical/source-derived claims rather than verified current economics.

## Safety and transparency

Synthetic personas should be explicitly represented as synthetic where required, and generated communication must not falsely imply a human relationship, medical authority, identity or consent. Agent automation must use platform-compliant APIs and explicit authorization.
